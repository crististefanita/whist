# Whist Lab 0.23.0

This behavior release improves contextual bidding and card play in Romanian Whist by using public bids, visible cards, remaining cards and contract progress.

## Changes since 0.22.1

- Condition bids and play decisions on opponents' contracts and cards already seen.
- Reweight honor-card protection, suit control and trick avoidance as the hand develops.
- Preserve Normal's contract-focused policy while Hard can disrupt opponents late when its own target is no longer attainable.
