# Whist 0.23.1

Această ediție Android de mentenanță reia calificarea din dovezi validate și reutilizează suitele neafectate; regulile jocului și fluxurile utilizatorului rămân neschimbate.

## Descărcare

- [APK](https://github.com/crististefanita/whist/releases/download/v0.23.1/WhistLab-0.23.1.apk)
- [SHA-256](https://github.com/crististefanita/whist/releases/download/v0.23.1/WhistLab-0.23.1.apk.sha256)

## Schimbări față de 0.23.0

- Reia calificarea din dovezi validate și rulează doar selecția de componente afectată de diff-ul sursei.
- Reutilizează cele nouă grupuri de componente neschimbate, cu rapoarte și receipt-uri legate de sursa lor.
- Menține livrarea nativă iOS în așteptare; Android rămâne ținta activă a release-ului.
