## Pe scurt

[Extent-ul canonic](component-report.html) conține fiecare comparație originală admisă și rezultatul nou al reluării. Este autonom; identitățile imuabile ale încercărilor și valorile SHA-256 sunt capturate în interiorul său.

[Observații originale](attempts/original-report.html) · [Execuția reluării](attempts/retry-report.html) · [Checkpoint original](attempts/original-checkpoint.json) · [Execuția finală](execution.json)

Un prefix capturat este declarat explicit ca republicare când întreruperea a împiedicat publicarea HTML-ului original. Eșecul original nu este editat și nu este prezentat ca PASS original.
