# Whist Lab 0.25.0

Prezentare comună, integritatea checkpoint-urilor și reluarea calificată a release-ului.

## Modificări

- Păstrează salvările deteriorate pentru diagnostic și menține recuperarea checkpoint-urilor pe API 24.
- Aliniază acțiunile principale și secundare ale meniurilor prin tipografia comună Android și Web.
- Separă dovezile eșantioanelor de licitare și validează domeniul modelului AI pentru o carte.
- Reia numai controalele de sursă lipsă sau eșuate, cu identități sigilate ale sursei, compilatorului și catalogului.
