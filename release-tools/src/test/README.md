# Testele de componentă release-tools

## Pe scurt

Această rădăcină de surse deține testele de componentă JVM focalizate pentru modulul Maven `release-tools`. Suita verifică descoperirea portabilă a rădăcinii proiectului, octeții exacți ai dovezilor, admiterea RAG consultativă, continuitatea certificatului de semnare și granița dintre adaptoarele de release și proprietarii testelor de joc.

[Strategia comună de testare](../../../docs/testing/README.md) definește alegerea nivelurilor, proprietatea raportului Extent, dovezile legate de sursă și cerințele cazurilor negative. Schimbările din aceste teste sunt calificate prin selecția de componente `release-tools`.
