# Fixture-uri neutre de prezentare

## Pe scurt

Observațiile imuabile și aserțiunile de continuitate aparțin contractului comun de prezentare. Nu conțin reguli de joc, widgeturi de platformă sau invocări executabile de teste. Adaptoarele furnizează stări publice legale; același oracol compară fiecare loc înainte și după tranziție.

## Limita verificării

Componentele producătorului și adaptoarele consumatoare verifică fixture-urile. Testele unitare izolate verifică proprietatea snapshot-urilor. Fixture-urile nu publică raport separat și nu creează o populație suplimentară de teste.

Urmărește [strategia comună de testare](../../../../docs/testing/README.md) pentru niveluri, dovezi și reutilizare.
