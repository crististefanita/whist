# Unități izolate de prezentare

## Pe scurt

Acest set de surse verifică proprietatea snapshot-urilor imuabile și normalizarea fixture-urilor portabile de prezentare. Cazurile rulează prin `:card-table-core:unitTest` fără Android sau browser.

## Limita verificării

Testele unitare păstrează diagnostice JUnit fără Extent. Matricele de geometrie și comportamentul adaptoarelor aparțin colecțiilor de componente; acceptanța vizuală rămâne o limită de platformă.

Urmărește [strategia comună de testare](../../../../docs/testing/README.md) pentru selecție și raportare.
