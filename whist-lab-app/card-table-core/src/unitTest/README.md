# Isolated presentation units

## Overview

This source set verifies immutable snapshot ownership and normalization in the portable presentation fixtures. Cases run through `:card-table-core:unitTest` without Android or a browser.

## Verification boundary

Unit cases retain JUnit diagnostics without Extent. Geometry matrices and game adapter behavior belong to component collections; rendered acceptance remains a platform boundary.

Follow the [shared testing strategy](../../../../docs/testing/README.md) for selection and reporting.
